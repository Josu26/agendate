# AgenDate — UI Experiment

**Historical exploratory React project · Not a shipped appointment product**

This public repository contains an early user-interface experiment built from a **Glitch React/Vite starter**. Parts of the UI were customized, but the current code and repository artifacts do not substantiate a complete booking service, customer management backend or production deployment.

## What is here

- A React/Vite frontend project, with routes and UI files under `src/`.
- Basic interface assets and experiments.
- A `package.json` still referencing the original Glitch starter; dependencies and engine constraints have not been reviewed for modern deployment.

## Context and limits

This is a historical exploration rather than current professional product work. There is no demonstrated end-to-end appointment workflow, persisted scheduling state, verified authentication, API contract, automated tests or deployment pipeline in this README.

To inspect the source, start with `package.json` and `src/`. A fresh local build has **not** been verified as part of this documentation update.
